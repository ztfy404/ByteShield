# Как пользоваться ByteShield

## Движки

- `auto` — использует `clamscan` из PATH, если он найден, иначе встроенную базу.
- `builtin` — SHA-256 и контрольная строка EICAR. В комплекте только тестовая сигнатура.
- `clamav` — требует установленный ClamAV. Если его нет или база не загрузилась, программа выдаёт ошибку, а не результат «всё чисто».

ClamAV можно установить по [официальной инструкции](https://docs.clamav.net/manual/Installing.html). В Debian/Ubuntu пакеты обычно устанавливаются через `sudo apt install clamav`, но затем нужно настроить обновление баз через `freshclam` или службу дистрибутива. Не запускайте два обновления базы одновременно.

На Windows нужно установить ClamAV для Windows, настроить базы и добавить папку с `clamscan.exe` в PATH. Проверка установки:

```bash
clamscan --version
```

ByteShield сам не скачивает движок и не обновляет его базы. Проверка реальных файлов в режиме ClamAV требует рабочего движка и актуальных баз. Проверка архивов и её пределы зависят от настроек ClamAV; встроенный движок архивы не распаковывает.

## Карантин

В окне сначала выберите строку с обнаружением и нажмите «В карантин». Программа сверяет SHA-256, сохраняет копию и метаданные и только после этого удаляет исходный файл. Если содержимое изменилось после проверки, перенос отменяется.

Хранилище по умолчанию:

- Windows: `%LOCALAPPDATA%/ByteShield/quarantine`.
- Linux: `${XDG_DATA_HOME:-~/.local/share}/ByteShield/quarantine`.

Копии получают случайные имена `.bin`; карантин не шифруется. Не открывайте его файлы вручную. Восстановление создаёт копию по выбранному пути и оставляет резерв в карантине. Существующий файл назначения не перезаписывается. Не восстанавливайте обнаружение, если не уверены в его безопасности.

Через CLI перенос можно явно выполнить для любого выбранного обычного файла:

```bash
python -m byteshield quarantine "путь/к/файлу"
python -m byteshield list
python -m byteshield restore ID --to "путь/к/новому/файлу"
```

Для отдельного хранилища аргумент задаётся перед командой:

```bash
python -m byteshield --quarantine-dir "путь/к/карантину" list
```

Каталог карантина исключён из сканирования. Сканер не следует по символьным ссылкам и не обрабатывает устройства и каналы как обычные файлы.

## Своя SHA-256 база

Встроенная база лежит в `byteshield/data/signatures.json`. Для отдельной базы нужен JSON формата:

```json
{
  "version": 1,
  "sha256": {
    "ПОЛНЫЙ_64_ЗНАЧНЫЙ_SHA256": "Название обнаружения"
  }
}
```

Заполнитель нужно заменить настоящим шестнадцатеричным SHA-256. Любая строка не становится сигнатурой автоматически: программа проверяет формат.

```bash
python -m byteshield scan "путь/к/файлу" --signatures my-signatures.json
```

## Тестирование

Для проверки обнаружения подходит безопасный [тест EICAR](https://www.eicar.org/download-anti-malware-testfile/). Он не является вирусом, но установленный антивирус может его заблокировать. В тестах ByteShield строка создаётся во временной папке; искать и скачивать реальные вирусы для проверки не требуется.

## Отчёт и коды возврата

Отчёт сохраняется только по команде пользователя и включает пути, SHA-256, обнаружения, ошибки, пропуски и признак отмены. Он остаётся на компьютере. При передаче отчёта учитывайте, что пути могут содержать личные сведения.

CLI возвращает `0`, если нет обнаружений и ошибок, `1` при обнаружении, `2` при ошибке (даже если есть обнаружения) и `130` при прерывании. Файлы, пропущенные из-за лимита, перечисляются отдельно; код `0` не означает, что пропусков нет.

Во время проверки одного файла ClamAV кнопка отмены может ждать завершения внешнего процесса, не более установленного таймаута в 60 секунд.
