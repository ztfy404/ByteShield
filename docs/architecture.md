# Как я устроил проект

Я разделил программу на несколько частей, чтобы окно и команды терминала использовали один сканер.

```text
app.py / gui.py ─┐
                ├── scanner.py ── SHA-256 / EICAR / clamscan
cli.py ─────────┘
                ├── quarantine.py ── копии + контрольные суммы
                └── report.py ── JSON-отчёт
```

- `scanner.py` читает файлы блоками, считает SHA-256, ищет тестовую строку и при необходимости вызывает ClamAV. Проверяемые файлы не запускаются.
- `gui.py` показывает результаты. Проверка идёт в отдельном потоке, результаты передаются через очередь, элементы Tkinter обновляются в основном потоке.
- `quarantine.py` хранит копии под случайными именами и проверяет контрольные суммы. Метаданные отделены от самих файлов. При восстановлении существующие файлы не заменяются.
- `report.py` сохраняет результат через временный файл, чтобы не оставлять наполовину записанный отчёт.
- `tests/` содержит проверки основных сценариев, ошибок и восстановления.

Вызов `clamscan` выполняется списком аргументов без shell. Пароли и облачные API программе не нужны.

Это пользовательское приложение для проверки по запросу. В нём нет драйвера, защиты от вмешательства вредоносного процесса и системного перехвата файлов. Для реальной базовой защиты Windows я оставляю Microsoft Defender включённым.
